# Livres et membres

Un **livre** est un ensemble de finances totalement séparé : son journal, ses comptes, ses données de référence et ses budgets. Rien n'est partagé entre les livres. Une organisation courante : un livre personnel par personne et un livre pour le foyer.

## Rôles

Chaque membre a un rôle dans chaque livre :

| Rôle             | Peut                                                    |
| ---------------- | ------------------------------------------------------- |
| **Propriétaire** | Tout, y compris les membres et les données de référence |
| **Éditeur**      | Saisir les opérations et les budgets                    |
| **Lecteur**      | Lire seulement                                          |

Un livre à un seul membre est privé ; à plusieurs, il est partagé.

L'onglet du navigateur porte le nom du livre ouvert et de la page affichée : un marque-page les reprend.

## Paramètres et membres

Ouvrez **Paramètres et membres** dans le menu du livre. Un propriétaire peut :

- choisir les **langues** du livre. Les catégories et comptes ont un nom dans chacune ; chaque membre les lit dans sa langue, ou dans la langue par défaut du livre quand une traduction manque ;
- **ajouter ou retirer des membres**. Les utilisateurs sont créés par le super utilisateur, sur la page **Utilisateurs** ;
- supprimer le livre.

Un membre peut quitter un livre.

## Exporter et importer un livre

**Exporter le livre**, dans le menu du livre (propriétaires seulement), télécharge tout le livre dans un fichier : données de référence, comptes, journal, budgets, règles et relevés importés. Les membres n'en font pas partie.

**Importer un livre**, sur la liste des livres, crée un **nouveau** livre à partir d'un tel fichier, sur cette installation ou une autre ; vous en êtes le propriétaire. Rien n'est jamais fusionné ni remplacé : pour revenir à une copie, importez-la, comparez, puis supprimez l'ancien livre. Une installation plus ancienne que celle qui a écrit le fichier peut le refuser : mettez-la à jour d'abord.

Le fichier contient en clair les numéros de compte et les libellés de la banque : rangez-le comme un relevé.

## Le super utilisateur

Le super utilisateur gère l'installation : il crée les utilisateurs et fixe leur mot de passe initial. Il **ne voit pas** les données d'un livre dont il n'est pas membre.

## Votre mot de passe

**Changer mon mot de passe** se trouve dans le menu. Vos autres appareils sont déconnectés ; celui-ci reste connecté.
