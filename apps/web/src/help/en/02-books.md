# Books and members

A **book** is a fully separate set of finances: its own journal, accounts, reference data and budgets. Nothing is shared between books. A typical setup is one private book per person plus one for the household.

## Roles

Each member has a role in each book:

| Role       | Can                                              |
| ---------- | ------------------------------------------------ |
| **Owner**  | Everything, including members and reference data |
| **Editor** | Enter transactions and budgets                   |
| **Viewer** | Read only                                        |

A book with one member is private; with several, it is shared.

The browser tab carries the name of the open book and of the page shown, and a bookmark takes it over.

## Settings and members

Open **Settings and members** in the book's menu. An owner can:

- choose the **languages** of the book. Categories and accounts get a name in each; every member reads them in their own language, or in the book's default one when a translation is missing;
- **add or remove members**. Users are created by the super user, on the **Users** page;
- delete the book.

A member can leave a book.

## Exporting and importing a book

**Export the book**, in the book's menu (owners only), downloads the whole book as one file: reference data, accounts, journal, budgets, rules and imported statements. Members are not part of it.

**Import a book**, on the list of books, creates a **new** book from such a file, on this installation or another one; you are its owner. Nothing is ever merged or replaced: to go back to a copy, import it, compare, then delete the old book. An installation older than the one that wrote the file may refuse it: update it first.

The file holds account numbers and bank labels in clear text: keep it as you would a bank statement.

## The super user

The super user maintains the installation: it creates users and sets their initial password. It does **not** see a book's data unless it is a member of that book.

## Your password

**Change my password** is in the menu. Your other devices are signed out; this one stays signed in.
